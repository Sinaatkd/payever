# MockPayment Project  

This project simulates a contactless payment processing system using a **mock payment SDK** in **React Native** with a **native Android module**.

---

## **📌 Features**
- Native Android SDK simulation in Java.
- React Native integration using a native module bridge.
- A simple UI for initializing the SDK and processing payments.
- Basic logging and error handling.

---

## **🚀 Getting Started**

### **1️⃣ Prerequisites**
Ensure you have the following installed:
- **Android SDK 30+**
- **Node.js 18+**
- **React Native CLI**
- **JDK 11+**
- **Android Emulator or Physical Device (with NFC enabled for real Tap-to-Phone usage)**

---

### **2️⃣ Running the App**
Follow the steps below in order:
- **clone the project from https://github.com/Sinaatkd/payever**
- **npm install**
- **build android/ folder using Android Studio**
- **npx react-native doctor**
- **npm run android**

### **3️⃣ Running test**
Follow the below command:
- **npm test**
